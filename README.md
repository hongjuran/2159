# 2159 — 주민등록번호 마스킹 도구

파일을 첨부하고 **실행** 버튼을 누르면 파일 안의 주민등록번호(YYMMDD-N######)를 자동으로 찾아 마스킹하는 웹 도구입니다.

- 지원 형식: TXT, CSV, TSV, LOG, JSON, MD, XLSX, XLS
- 모든 처리는 브라우저 안에서만 이루어지며, 파일 내용은 서버로 전송되지 않습니다.
- 마스킹 규칙: 생년월일 6자리와 뒤 첫 번째 숫자(성별/세기 구분)만 남기고 나머지 6자리를 `*`로 대체합니다.
  - 예: `901231-1234567` → `901231-1******`
- 원본에 구분자(`-`)가 없어도(`9012311234567`) 인식해 동일한 자리만 마스킹합니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다 (더블클릭하거나 간단한 정적 서버로 실행).
2. 파일을 드래그 앤 드롭하거나 "파일 선택"으로 첨부합니다.
3. 텍스트 파일을 EUC-KR/CP949로 저장했다면 인코딩을 선택합니다.
4. **실행**을 누르면 마스킹 결과 미리보기가 표시됩니다.
5. **마스킹된 파일 다운로드**로 결과 파일을 저장합니다. (텍스트 결과는 UTF-8로 저장됩니다)

## 로컬 실행 (정적 서버)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 구조

- `index.html` — 페이지 마크업
- `css/style.css` — 스타일
- `js/app.js` — 파일 읽기, 마스킹 로직, 엑셀 처리, 다운로드
- `js/xlsx.full.min.js` — 엑셀(.xlsx/.xls) 파싱/생성을 위한 [SheetJS](https://sheetjs.com/) 라이브러리 (오프라인 동작을 위해 로컬에 포함)
