# 2159 — 주민등록번호 마스킹 도구

파일을 첨부하고 **실행** 버튼을 누르면 파일 안의 주민등록번호(YYMMDD-N######)를 자동으로 찾아 마스킹하는 웹 도구입니다.

- 지원 형식: TXT, CSV, TSV, LOG, JSON, MD, XLSX, XLS, PDF, PNG, JPG, BMP, WEBP
- 모든 처리는 브라우저 안에서만 이루어지며, 파일 내용은 서버로 전송되지 않습니다.
- 마스킹 규칙: 생년월일 6자리와 뒤 첫 번째 숫자(성별/세기 구분)만 남기고 나머지 6자리를 가립니다.
  - 텍스트·엑셀은 **별표(`*`)** 또는 **검정 블록(`█`)** 중 원하는 방식을 선택할 수 있습니다.
  - 이미지·PDF는 OCR로 찾은 위치를 항상 검은 사각형으로 덮습니다.
  - 예: `901231-1234567` → `901231-1******` 또는 `901231-1██████`
- 원본에 구분자(`-`)가 없어도(`9012311234567`) 인식해 동일한 자리만 마스킹합니다.

## 파일 형식별 동작

- **TXT / CSV / TSV / LOG / JSON / MD**: 정규식으로 번호를 찾아 선택한 마스킹 방식(별표/검정 블록)으로 치환합니다.
- **XLSX / XLS**: 모든 시트의 각 셀을 검사해 선택한 마스킹 방식으로 치환합니다.
- **PNG / JPG / BMP / WEBP**: 브라우저 내 OCR(문자 인식, [Tesseract.js](https://tesseract.projectnaptha.com/))으로
  번호가 적힌 위치를 찾아 검은 사각형으로 덮은 새 이미지를 만듭니다.
- **PDF**: 페이지마다 먼저 PDF의 텍스트 레이어에서 번호를 찾고(디지털 문서), 텍스트 레이어가 없는 페이지(스캔 문서)는
  OCR로 대체 인식합니다. 결과 PDF는 마스킹이 반영된 페이지 이미지로 다시 조립되므로, 검은 사각형 아래에
  원본 글자가 텍스트로 남아있지 않습니다(복사/추출로 복구 불가).

⚠️ OCR 인식 정확도는 이미지 화질·글꼴·해상도에 따라 달라질 수 있습니다. 다운로드 전 미리보기에서 마스킹이
정확히 적용됐는지 반드시 확인하세요.

## 사용 방법

1. `index.html`을 정적 서버로 엽니다 (아래 "로컬 실행" 참고. `file://`로 직접 열면 일부 라이브러리가 동작하지 않을 수 있습니다).
2. 파일을 드래그 앤 드롭하거나 "파일 선택"으로 첨부합니다.
3. 텍스트 파일을 EUC-KR/CP949로 저장했다면 인코딩을 선택합니다.
4. **실행**을 누르면 마스킹 결과 미리보기가 표시됩니다. (이미지/PDF는 OCR 처리로 수 초~수십 초 걸릴 수 있습니다)
5. **마스킹된 파일 다운로드**로 결과 파일을 저장합니다. (텍스트 결과는 UTF-8로 저장됩니다)

## 로컬 실행 (정적 서버)

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 구조

- `index.html` — 페이지 마크업
- `css/style.css` — 스타일
- `js/app.js` — 파일 읽기, 마스킹 로직(텍스트/엑셀/이미지 OCR/PDF), 다운로드
- `js/xlsx.full.min.js` — 엑셀(.xlsx/.xls) 파싱/생성을 위한 [SheetJS](https://sheetjs.com/)
- `js/pdf.min.js`, `js/pdf.worker.min.js` — PDF 렌더링/텍스트 추출을 위한 [pdf.js](https://mozilla.github.io/pdf.js/)
- `js/pdf-lib.min.js` — 마스킹된 페이지로 새 PDF를 조립하기 위한 [pdf-lib](https://pdf-lib.js.org/)
- `js/tesseract/` — 이미지·스캔 PDF의 문자 인식을 위한 [Tesseract.js](https://tesseract.projectnaptha.com/)
  (`tesseract.min.js`, `worker.min.js`, `core/`의 WASM 엔진, `lang/eng.traineddata.gz` 영어+숫자 인식 데이터)

모든 라이브러리는 완전한 오프라인 동작과 개인정보 보호를 위해 CDN 대신 저장소에 직접 포함했습니다.
