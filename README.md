## Y2K 스티커사진 스튜디오

2000년대 한국식 스티커사진(인생네컷) 감성의 브라우저 대시보드입니다. 사진을 첨부하면 20가지 Y2K 템플릿 중 골라서 프레임을 씌우고, 펜/스탬프 도구로 낙서를 더한 뒤 PNG로 다운로드할 수 있습니다.

### 실행 방법

빌드 없이 정적 파일 하나로 동작합니다.

```bash
# 그냥 브라우저에서 index.html을 열거나
open index.html

# 또는 로컬 서버로 실행
python3 -m http.server 8000
# http://localhost:8000 접속
```

### 기능

- 사진 첨부(최대 4장), 그리드형 템플릿은 여러 장을 순서대로 배치, 1장만 올려도 모든 칸 자동 채움
- 20가지 Y2K 템플릿(하트, 홀로그램, 필름, 디스코, 사이버, 폴라로이드 등) — 레이아웃/패턴/프레임/스탬프 문구가 캔버스로 실시간 렌더링됨
- 펜 / 지우개 / 이모지 스탬프 도구, 색상 스와치 + 커스텀 컬러, 굵기 조절, 실행취소, 낙서 지우기
- 완성한 스티커사진을 PNG로 다운로드
- 모든 처리는 브라우저(Canvas API)에서만 이루어지며 사진은 어디로도 전송되지 않음
